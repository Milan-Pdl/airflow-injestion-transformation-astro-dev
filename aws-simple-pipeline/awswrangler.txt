awswrangler (now officially called AWS SDK for pandas) is an open-source Python library that makes it much easier to work with AWS data services using pandas and PyArrow.

Instead of writing a lot of low-level AWS API code with boto3, you can use awswrangler to read and write data in just a few lines.

Why use it?

Without awswrangler, you might need to:

Download a file from Amazon S3 using boto3.
Save it locally.
Read it into pandas.

With awswrangler, you can read it directly:

import awswrangler as wr

df = wr.s3.read_csv("s3://my-bucket/data.csv")
Common use cases
1. Read data from Amazon S3
import awswrangler as wr

df = wr.s3.read_parquet("s3://my-bucket/sales/")
2. Write a DataFrame to S3
wr.s3.to_parquet(
    df=df,
    path="s3://my-bucket/output/"
)
3. Run an Amazon Athena query
df = wr.athena.read_sql_query(
    sql="SELECT * FROM sales",
    database="analytics"
)

This executes the query in Athena and returns the results as a pandas DataFrame.

4. Read from the AWS Glue Data Catalog
df = wr.athena.read_sql_table(
    table="customers",
    database="analytics"
)
Services it supports

Some of the AWS services it integrates with include:

Amazon S3 – Read and write CSV, Parquet, JSON, Excel, etc.
Amazon Athena – Run SQL queries.
AWS Glue – Manage tables and metadata.
Amazon Redshift – Load and unload data.
Amazon DynamoDB – Read and write items.
Amazon Timestream – Query time-series data.
Relationship with boto3
boto3 is the official low-level AWS SDK for Python. It gives you direct access to AWS APIs.
awswrangler is a higher-level library built on top of boto3, designed specifically for data engineering and analytics workflows.

For example, using boto3 to download a CSV from S3 involves creating an S3 client, fetching the object, and parsing it. With awswrangler, it's a single function call:

import awswrangler as wr

df = wr.s3.read_csv("s3://my-bucket/customers.csv")
When would you use it?

awswrangler is especially useful if you're building:

ETL/ELT pipelines
Data engineering workflows
Analytics pipelines
Machine learning data preparation
AWS Lambda functions that process data
AWS Glue jobs

In short, if you're working with pandas DataFrames and data stored in AWS, awswrangler provides a much simpler and more Pythonic interface than using boto3 directly.
